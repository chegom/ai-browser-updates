# AI Browser for Windows

AI Browser의 공개 Windows 설치 파일과 자동 업데이트 메타데이터 저장소입니다.
소스 코드는 포함하지 않습니다.

## 설치

[최신 Windows 설치 파일 받기](https://github.com/chegom/ai-browser-updates/releases/latest)

Release 페이지에서 `AI-Browser-Setup-*-x64.exe`를 내려받아 실행합니다. 이 updater 포함
버전을 한 번 설치하면 이후 버전은 앱이 백그라운드에서 내려받고 상단의
`재시작하여 적용` 버튼으로 설치합니다.

현재 테스트 빌드는 코드 서명되지 않았으므로 Windows SmartScreen에서
`알 수 없는 게시자` 경고가 표시될 수 있습니다. 설치 파일 외의 `latest.yml`과
`.blockmap` 파일은 자동 업데이트용입니다.
